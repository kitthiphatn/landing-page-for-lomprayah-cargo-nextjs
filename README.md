# Lomprayah Cargo: landing page

เว็บหน้าแรกและหน้าติดตามพัสดุของ Lomprayah Cargo สร้างด้วย Next.js และ Payload CMS (หลังบ้านอยู่ที่ `/admin`)

- ภาษา TH/EN: `/th/...` และ `/en/...` (เข้า `/` จะพาไปภาษาที่เคยเลือก หรือตามภาษาเบราว์เซอร์)
- โหมดสว่าง/มืด: ครั้งแรกตามเครื่อง จากนั้นจำค่าที่เลือก
- แบนเนอร์ขออนุญาตคุกกี้ (PDPA): ค่าที่เลือกเก็บในคุกกี้ `lp_consent` ใช้ `readConsent()` ใน `src/lib/consent.ts` ก่อนโหลดสคริปต์วิเคราะห์หรือโฆษณา
- ฐานข้อมูล SQLite อยู่ในโฟลเดอร์ `data/` ของเว็บนี้เอง ไม่ใช้ฐานข้อมูลร่วมกับเว็บอื่นบนเซิร์ฟเวอร์

## เริ่มพัฒนา

```bash
cp .env.example .env   # แล้วตั้ง PAYLOAD_SECRET
npm install
npm run dev            # http://localhost:3005 และ http://localhost:3005/admin
```

ครั้งแรกที่เปิด `/admin` จะให้สร้างผู้ใช้คนแรก (ตั้ง role เป็น admin)

### ทดสอบหน้าติดตามพัสดุโดยไม่ต่อ API จริง

```bash
npm run mock-api                      # API จำลองที่ http://localhost:4500/api
# ใน .env ตั้ง TRACKING_API_UPSTREAM=http://localhost:4500/api แล้วรัน npm run dev
```

เลขตัวอย่าง: `LP-TAO-261005-0003` (อยู่บนเรือ), `LP-SMI-261012-0141` (ส่งสำเร็จ), `LP-CPN-261014-0027` (รอรับพัสดุ), `LP-PNG-261001-0009` (ตีกลับ)

## หน้าติดตามพัสดุ

`/th/track/เลข1,เลข2` ดึงข้อมูลจาก API ของระบบหลักผ่านเบราว์เซอร์ของลูกค้า แสดงรายการพัสดุพร้อม timeline, แผนที่เส้นทาง (OpenStreetMap) และการ์ดติดตามสด หน้านี้ตั้ง `noindex` เพราะมีข้อมูลลูกค้า (แบบปิดบังแล้ว)

- บน `www.lomprayahcargo.com`: ตั้ง `NEXT_PUBLIC_TRACKING_API=https://api.lomprayahcargo.com/api` เบราว์เซอร์ลูกค้าจะเรียก API ตรง rate limit 60 ครั้ง/นาทีจะนับแยกต่อลูกค้า
- เว็บจริงอยู่โดเมนอื่นที่ไม่ใช่ lomprayahcargo.com: ต้องเพิ่มโดเมนนั้นใน CORS ของ API ก่อน แล้วจึงตั้ง `NEXT_PUBLIC_TRACKING_API` ได้
- dev, preview: เว้นว่างไว้ ระบบจะส่งผ่าน `/tracking-api` ของเว็บนี้ เพราะ API อนุญาต CORS เฉพาะ lomprayahcargo.com (ทุกคำขอจะนับ rate limit รวมกันที่ IP ของเซิร์ฟเวอร์)

## ใส่เนื้อหาตั้งต้น

```bash
npm run seed
```

เติมหลังบ้านด้วยเนื้อหาจาก lomprayah.com: ข่าว 18 เรื่อง (เป็นฉบับร่าง เลือกเผยแพร่เองเฉพาะเรื่องที่เข้ากับเว็บคาร์โก้), ข้อมูลติดต่อและโซเชียล, หน้าเกี่ยวกับเรา, การ์ดบริการ และ FAQ พื้นฐาน รันซ้ำได้ ไม่ทับข้อมูลที่กรอกไว้แล้ว รูปปกข่าวดาวน์โหลดจาก lomprayah.com ถ้าโหลดไม่ได้จะข้ามรูปนั้น

บทความและเส้นทางที่ยังเป็นฉบับร่าง กดปุ่ม "ดูตัวอย่าง" ในหน้าแก้ไขเพื่อดูหน้าเว็บจริงก่อนเผยแพร่ (ต้องล็อกอินหลังบ้านอยู่)

## เปลี่ยนโครงสร้างฐานข้อมูล

เมื่อเพิ่มหรือแก้ field ใน collection/global ให้สร้าง migration แล้ว commit ไปด้วย

```bash
npm run payload migrate:create ชื่อการเปลี่ยนแปลง
npm run generate:types
```

ตอนรันบน production ระบบจะ apply migration ที่ค้างอยู่ให้เองตอนเริ่ม

## Deploy บน Plesk (ไม่กระทบเว็บอื่น)

ทุกครั้งที่ merge เข้า `main` GitHub Actions จะ build เว็บแล้วเก็บไฟล์พร้อมรันไว้ใน Releases บนเซิร์ฟเวอร์รันคำสั่งเดียวเพื่อดาวน์โหลดและรีสตาร์ทเฉพาะเว็บนี้

```bash
bash /var/www/vhosts/lomprayahcargo.com/cargo-web/deploy.sh /var/www/vhosts/lomprayahcargo.com/cargo-web
```

ขั้นตอนตั้งค่าครั้งแรก, ค่า environment ใน Plesk, การย้อนเวอร์ชัน และ backup อยู่ใน [docs/deploy-plesk.md](docs/deploy-plesk.md)
